BEHIND THE FORGE / THE MATCHDAY WORLD

How do you turn availability into a fair, usable match plan?

Matchday is a chain of small decisions. A coach needs to know who is coming, which positions are covered and what changes after the first substitution. FootballForge brings that chain together for youth teams, with team-specific training schedules and a shared planning workspace.

01

Before kick-off

Maintain the squad, record attendance exceptions and select guest players for a particular match. Regular players and guests follow different availability rules.

02

Four moments, one match

The documented planner produces a starting formation and three substitution views. Manual changes recalculate the later lineups and substitution text.

03

Take the plan to the pitch

A local four-page PDF puts each formation and its substitutions on a separate page. The parent-message workflow also supports match communication and a downloadable poster.

The workflow, under the surface.

  1. Team workspace
  2. Availability + positions
  3. Lineup engine
  4. PDF / parent message

A simplified reading of the documented workflow.

01 / ENGINEERING NOTEKeep team changes scoped

The documented Supabase workflow merges the selected team's changes against the latest shared state using an updated_at comparison. This addresses one team's edits overwriting another team's data; it does not make browser access codes secure authentication.

02 / ENGINEERING NOTEProtect against an empty cloud response

The source documentation describes a browser recovery copy and a warning when remote data contains less team content than the local copy. The coach decides which version to retain. Production recovery has not been exercised by this showcase.

03 / ENGINEERING NOTEGenerate artifacts locally

lineup-engine.js handles formation decisions, matchday-pdf.js produces the PDF and parent-message.js prepares communications. The showcase demo uses fictional players and never connects to these team records.
