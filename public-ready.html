How downloads will work.

When an eligible project is ready, its Pipeline card can display the relevant actions automatically from our catalog. These are different distribution methods:

01 / GITHUB TEMPLATE

Use this template

In the GitHub repository settings, enable Template repository. Then provide the repository's real /generate link. Visitors can create a new repository from it; this is not the same as downloading a ZIP.

02 / RELEASE PACKAGE

Download a version

Provide a real GitHub Release or other approved package URL. Visitors download a versioned artifact, with an installation guide and license.

03 / GAMING ADDONS

CurseForge only

WoW addon downloads and updates stay on CurseForge. NOVYX showcases addons, their features and development status, but does not become an alternative download site.

One last gate. Then it's ready for the world.

Current NOVYX repositories have not yet been verified as public GitHub templates. The Pipeline will not invent template or download links.
