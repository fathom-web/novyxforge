BEHIND THE FORGE / THE LEGACY WORLD

What remains of an adventure after the session ends?

LifeForge approaches Warcraft as a personal history: recorded milestones, memories, observed companions and places visited. It is a native Lua addon for the intended Forever client, with a local data model. Its public source is an alpha, not a confirmed in-game release.

01

Record the journey

Build 7 documents character history, replay-safe milestone tiers and an observed zone atlas. History starts from recorded events; it cannot reconstruct adventures from before installation.

02

Keep the human moments

The source describes memories, favorites, future-self letters and a Memory Museum. These are implemented source features whose actual in-client behavior still requires validation.

03

Make room for real life

The related Forge AFK — Dad Mode repository documents twelve AFK reasons, a timer, silent mode and a return action. Its v1.0.0-beta.2 build also awaits game-client testing and CurseForge release.

The workflow, under the surface.

  1. Observed game events
  2. Lua data model

A simplified reading of the documented workflow.

01 / ENGINEERING NOTELocal records, meaningful evidence

LifeForge uses WoW SavedVariables and a versioned LF2 backup format. It records observed history instead of inventing old milestones. There is no companion website account or cloud character synchronization.

02 / ENGINEERING NOTEA test double is not a game client

The Build 7 README reports headless Lua and archive tests. They exercise logic but cannot establish rendering, combat behavior, API compatibility or reload persistence inside the real Forever client.

03 / ENGINEERING NOTEKeep distribution explicit

GitHub provides source and development evidence. The showcase offers no addon ZIP download; public releases and updates belong on a verified CurseForge page after client acceptance. Neither addon has a verified CurseForge release in this review.
