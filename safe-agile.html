SAFe Agile Forge.

Prototype in development

Turn an entire Program Increment into a clear, actionable plan. A browser-based ceremony planner and PI Event Command Center designed for RTEs, Product Managers, Product Owners and Scrum Masters.

Explore the project on GitHub ↗ View full project showcase ↗ See capabilities ↓

From ceremony to command center.

The prototype already contains working planning flows and local exports. It is still evolving and has not completed full browser or organizational acceptance testing.

01 / CEREMONIES

PI Ceremony Planner

Select an ART role, enter iteration dates, propose events and export a personal Outlook-compatible .ics calendar.

02 / EVENTS

PI Event Planner

Plan multi-ART sessions, room capacity, speakers, objectives, dependencies, risks and confidence votes.

03 / DELIVERABLES

Export & prepare

Create offline PDF plans and editable workbooks, with local browser storage and JSON backup.

Deployment status: The app source is available on GitHub. Its intended standalone address is safeforge.novyxforge.com; public hosting and HTTPS have not been verified.
