BEHIND THE FORGE / THE EXPERIMENT WORLD

What is the smallest useful version of an idea?

Spark Lab is a working browser workshop. Describe an idea, its audience and the problem, then take away a structured brief, starting steps and a reusable build prompt. It uses deterministic templates, not a remote AI model.

01

03

Take it with you

The workflow, under the surface.

  1. Idea + context
  2. Local templates
  3. Structured brief
  4. Copy / JSON export

A simplified reading of the documented workflow.

01 / ENGINEERING NOTEMake an experiment useful

The workshop runs in static HTML and JavaScript without a paid API or backend. Its output is a starting point for human review, not a validated feasibility assessment.

02 / ENGINEERING NOTEKeep the handoff visible

Visitors explicitly copy or download their brief. The page does not claim to create a repository, contact an AI service or submit an idea to NOVYX.
